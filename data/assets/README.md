# Local test assets

`npm run setup:local` downloads these files; the binaries are intentionally ignored by Git.

- `scattering-skull.glb` and `scattering-skull.jpg`: KhronosGroup/glTF-Sample-Assets, ScatteringSkull, CC0 1.0, model by Vladimir Petkovic.
- `sakura-garden.ply`: WakuFactory Gaussian Splatting sample `sakura1.ply`, CC0.
- `chess-set-photogrammetry.glb`: contributor-provided chess-set photogrammetry mesh; place the source file here manually using this filename.
- `chess-set-gs-31/`: SuperSplat scene `8053365a`, a SOG reconstruction generated from 31 photographs.
- `chess-set-gs-691/`: SuperSplat scene `65d2e9d3`, a SOG reconstruction generated from 691 photographs.

These are demonstration fixtures and are not IU collection objects. Confirm licensing and publication permission before any public deployment.
